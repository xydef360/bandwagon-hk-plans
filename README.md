## 关于带宽和流量，别被数字误导

搬瓦工香港套餐统一标1Gbps端口，但"1Gbps"是端口上限，不是保证带宽。500GB/月在1Gbps端口下理论上约够跑满带宽4小时，实际几乎跑不满——所以别拿这个数字和某些标"100Mbps不限流量"的小商家直接比，场景不同。

流量用超之后搬瓦工会限速到1Mbps左右，不会直接停机，但1Mbps基本没法用。如果你的业务有明显流量峰值（视频、大文件下载），算清楚月流量再下单。40G那档500GB对建站用户够用，对资源站、图床一类业务就捉襟见肘了。
